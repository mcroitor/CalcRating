# Задача 003: Импорт и экспорт списка шахматистов (CSV, XLSX, ODS, PDF, HTML)

## 1. Цель
Реализовать функционал пакетной загрузки (импорта) шахматистов из файлов популярных форматов (CSV, XLSX, ODS), а также выгрузку (экспорт) текущего реестра шахматистов в форматы PDF, XLSX и HTML.

## 2. Зависимости
- Выполнена Задача 002 (модель `Player`, таблица `ratings`, права доступа).

## 3. Требования к реализации

### 3.1. Библиотеки и зависимости
- `maatwebsite/excel` (или `phpoffice/phpspreadsheet`) для парсинга и генерации табличных файлов (CSV, XLSX, ODS).
- `barryvdh/laravel-dompdf` для генерации документов PDF.
- Версии пакетов должны быть совместимы с Laravel 12 и PHP 8.4+. При проблемах с `maatwebsite/excel` допускается прямая работа через `phpoffice/phpspreadsheet`.

### 3.2. Импорт шахматистов (CSV, XLSX, ODS)
- Доступен только для ролей `arbiter` и `admin`.
- Формат входного файла:
  - Колонки: `first_name`, `last_name`, `birth_date` (YYYY-MM-DD), `current_rating`, `title`, `notes`.
  - Заголовки колонок — машинные, латиницей (см. `questions.md` №10); подписи интерфейса и отчётов локализуются в `task_009`.
- Валидация при импорте:
  - Пропуск пустых строк.
  - Проверка формата даты.
  - Если титул не распознан — устанавливать значение `None`.
  - Рейтинг по умолчанию: 1000 (если колонка пуста).
- Обработка транзакции: создание записи в `players` и синхронное добавление стартовой точки в `ratings`.
- Частичный успех (`questions.md` №11):
  - Импорт выполняется чанками по 100–500 строк; каждый чанк — в отдельной транзакции.
  - Ошибки валидации отдельных строк не откатывают чанк: строка пропускается и попадает в отчёт.
  - Ошибка уровня БД откатывает текущий чанк и останавливает импорт; ранее загруженные чанки сохраняются.
- Дедупликация: строка с совпадением `last_name + first_name + birth_date` считается дубликатом, пропускается и попадает в отчет как предупреждение; существующий игрок не изменяется.
- Вывод понятного отчета пользователю: "Успешно импортировано: N, с ошибками: M" и список строк с причинами.

### 3.3. Экспорт шахматистов
- Доступен для ролей `arbiter` и `admin`.
- Доступные форматы:
  - **XLSX:** структурированная таблица со стилями заголовков.
  - **PDF:** чистый альбомный или книжный отчет с пагинацией и номерами страниц через DomPDF.
  - **HTML:** отдельная страница без бокового меню и скриптов (готовая для сохранения в файл или вывода на печать `window.print()`).
- В выгрузку попадают: Номер/ID, ФИО, Дата рождения, Возраст, Титул, Текущий рейтинг.
- В XLSX заголовки колонок — латиницей (`id`, `last_name`, `first_name`, `birth_date`, `age`, `title`, `current_rating`); в PDF/HTML — подписи по локали запроса (`questions.md` №10, `task_009`).
- Поддержка экспорта с учетом текущих фильтров (если в UI применен фильтр по титулу или рейтингу).

### 3.4. Подзадачи реализации
- [x] **3.1. Установка и настройка зависимостей:** Установка пакетов `maatwebsite/excel` и `barryvdh/laravel-dompdf`, публикация конфигураций и регистрация сервис-провайдеров.
- [x] **3.2. Логика импорта (`ImportPlayersAction`):** Создание Action с правилами валидации строк, автоматическим парсингом дат, чанковой обработкой, частичным успехом и созданием стартовых точек в `ratings`.
- [x] **3.3. UI импорта и обработка ошибок:** Модальное окно/страница загрузки файлов (CSV, XLSX, ODS), flash-сообщения об успехе или подробный список строк с ошибками.
- [x] **3.4. Экспорт в форматы XLSX и HTML:** Класс `PlayersExport` для выгрузки Excel; легковесный Blade-шаблон `players.export-html` без навигации для печати.
- [x] **3.5. Экспорт в PDF:** Blade-шаблон `players.export-pdf`, подключение шрифта DejaVu Sans для кириллицы, генерация стрима/скачивания через DomPDF.

## 4. Критерии приемки (DoD)
1. Успешный импорт корректных файлов `.csv`, `.xlsx`, `.ods`.
2. При загрузке битого файла или файла с неверными заголовками приложение не падает с 500 ошибкой, а выводит читаемое сообщение об ошибке валидации.
3. Скачиваемый XLSX открывается в MS Excel / LibreOffice без предупреждений о повреждении.
4. Скачиваемый PDF корректно отображает кириллицу (подключен UTF-8 шрифт DejaVu Sans).
5. HTML-экспорт открывается как автономная веб-страница.
6. Неавторизованный пользователь и гость получают 403 при обращении к маршрутам импорта/экспорта.
7. При частично некорректном файле импорт сохраняет успешные чанки, возвращает отчёт «N / M» со списком ошибочных строк; ошибка БД откатывает только текущий чанк и останавливает импорт.

## 5. Проверка и тесты
- Feature-тест импорта тестового CSV-файла с фиксацией количества добавленных записей в БД.
- Feature-тест частичного успеха: корректные строки сохраняются, ошибочные попадают в отчёт; ошибка БД откатывает только текущий чанк.
- Feature-тест дедупликации по `last_name + first_name + birth_date`: дубликат пропускается, существующий игрок не изменяется.
- Feature-тест проверки отдачи корректных MIME-типов и заголовков при экспорте (PDF, XLSX, HTML).

## 6. Риски и допущения

- `maatwebsite/excel` и DomPDF могут иметь ограничения совместимости с Laravel 12 / PHP 8.4; версии фиксируются, предусмотрен fallback на `phpoffice/phpspreadsheet`.
- Большие файлы могут приводить к превышению `memory_limit` и `max_execution_time`; импорт выполняется чанками по 100–500 строк, каждый чанк — в отдельной транзакции, размер файла ограничивается.
- CSV может быть в UTF-8 или Windows-1251, с разными разделителями; кодировка и разделитель определяются явно и указываются в отчёте об импорте.
- Даты могут приходить в разных форматах; ожидается `YYYY-MM-DD`, остальные форматы отклоняются с понятной ошибкой.
- PDF с кириллицей требует встроенного UTF-8 шрифта (DejaVu Sans); проверить переносы и пагинацию.
- Экспорт CSV/XLSX должен защищаться от formula injection: значения, начинающиеся с `=`, `+`, `-`, `@`, экранируются.
- Предполагается, что импорт создает новых игроков и не обновляет существующих.

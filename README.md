# CalcRating

Приложение для ведения реестра шахматистов, проведения турниров и расчета индивидуального рейтинга по формуле Elo.

> Реализованы все задачи **000–010**: каркас Laravel, авторизация и роли, реестр шахматистов с историей рейтинга, импорт и экспорт, турниры и управление составом, жеребьёвка (круговая, швейцарская, олимпийская), ввод результатов и турнирная таблица с tiebreak, расчёт Elo в двух режимах и закрытие турнира, экспорт турнирных протоколов, админ-панель управления пользователями, мультиязычный интерфейс (`en` по умолчанию, `ru` с переключением через сессию и cookie), шахматные клубы, членство игроков и клубные турниры, а также production-конфигурация, CI-сборка, команды резервного копирования/проверки SQLite и эксплуатационный runbook.

## Реализовано

- Авторизация и роли `guest` / `arbiter` / `admin`, оптимистичная блокировка и обработка `409`.
- Реестр шахматистов: CRUD, поиск и фильтры, история рейтингов, график Chart.js.
- Импорт CSV/XLSX/ODS с частичным успехом и дедупликацией; экспорт реестра в XLSX, PDF и HTML.
- Турниры: создание и редактирование, статусы `draft` / `in_progress` / `completed`, два режима расчёта Elo, состав участников, фиксация `rating_before` при старте, публичная турнирная таблица с детерминированным tiebreak.
- Жеребьёвка и туры: полное расписание круговой системы, генерация туров по швейцарской и олимпийской системам, bye, ввод результатов партий с оптимистичной блокировкой (`409`), пересчёт очков, личные встречи и стадия выбывания в таблице.
- Экспорт турнирных протоколов: XLSX (шапка, итоговая таблица, листы туров), PDF и HTML для печати; доступ только для `arbiter` и `admin`.
- Админ-панель пользователей: поиск и фильтры, создание со ссылкой сброса пароля, смена роли, блокировка/разблокировка с завершением сессий и audit-логом; заблокированный пользователь не может войти.
- Мультиязычный интерфейс (`en`/`ru`): английский по умолчанию, переключатель `EN | RU` без изменения URL (сессия + cookie на 1 год, `Vary: Cookie`), локализация всех экранов, валидации, flash-сообщений, ответов `409`, уведомлений и печатных форм PDF/HTML при сохранении латинских машинных заголовков XLSX/CSV.
- Шахматные клубы (`/clubs`): каталог и карточки с логотипами, штат клуба (`manager`/`arbiter`), множественное членство игроков (`0..N`) при едином реестре и едином Elo, обязательная привязка турниров к клубу, изоляция прав между клубами, привязка к клубу при импорте игроков и вывод клуба в протоколах турнира.

## Стек

- PHP 8.4+
- Laravel 12.x
- SQLite 3 (`database/database.sqlite`)
- Laravel Breeze: Blade + Tailwind CSS + Vite
- Chart.js через npm
- `maatwebsite/excel` для XLSX/CSV/ODS
- `barryvdh/laravel-dompdf` для PDF
- Два режима расчета Elo: по среднему рейтингу соперников и по каждой партии

## Установка

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
```

`package-lock.json` после первой установки стоит закоммитить: в дальнейшем используйте `npm ci` для воспроизводимой сборки.

Создать файл базы данных:

```powershell
New-Item -ItemType File -Path database/database.sqlite -Force
```

```bash
php artisan migrate --seed
php artisan storage:link
npm run build
php artisan serve
```

Приложение будет доступно по адресу `http://127.0.0.1:8000`.

### Учётные записи по умолчанию (только dev / demo)

Команда `php artisan migrate --seed` заполняет базу демонстрационными шахматистами, черновиком турнира и тремя тестовыми пользователями:

| Роль | Email | Пароль | Назначение |
|---|---|---|---|
| `admin` | `admin@example.com` | `password` | Полный доступ, админ-панель `/admin/users`, удаление турниров |
| `arbiter` | `arbiter@example.com` | `password` | Ведение реестра игроков, проведение и экспорт турниров |
| `guest` | `guest@example.com` | `password` | Просмотр реестра и турниров (чтение) |

> **Важно для production:** при `APP_ENV=production` запуск `DatabaseSeeder` заблокирован, чтобы тестовые учётные записи со стандартным паролем не попали на боевой сервер. На чистой базе используйте миграции без `--seed` и создайте первого администратора командой:
>
> ```bash
> php artisan migrate --force
> php artisan admin:bootstrap admin@yourdomain.com --name="Имя" --surname="Фамилия"
> ```
>
> Команда запросит пароль в скрытом интерактивном режиме (не сохраняя его в истории shell и `.env`) либо с флагом `--send-reset` сгенерирует случайный пароль и отправит ссылку для установки пароля на почту. Если пользователь уже зарегистрировался как `guest`, повысить его до `admin` можно флагом `--promote`.

## Разработка

Запуск Vite в режиме watch и PHP-сервера в двух терминалах:

```bash
npm run dev
php artisan serve
```

`PHP_CLI_SERVER_WORKERS` в `.env` закомментирован: многопроцессный dev-сервер работает только на POSIX и требует `php artisan serve --no-reload`. На Windows переменная всё равно игнорируется, а без флага Laravel выводит предупреждение и поднимает один воркер.

## Сборка фронтенда

```bash
npm ci && npm run build
```

Если `package-lock.json` еще нет (первый запуск), используйте `npm install && npm run build`.

Результат сборки попадает в `public/build`. Node.js нужен только на этапе сборки: production-серверу достаточно PHP. Если целевая площадка не имеет Node.js, собирайте ассеты в CI или локально и доставляйте `public/build` вместе с приложением.

## Принятые архитектурные решения

Зафиксированы в [`questions.md`](questions.md#принятые-ответы):

- шахматисты не связаны с пользователями (`players` — отдельный реестр);
- фронтенд собирается через Breeze + Vite + npm;
- tiebreak: очки → личная встреча (только для двух участников) → число побед → стартовый рейтинг → ID;
- параллельное участие в турнирах разрешено, `rating_before` фиксируется при старте турнира;
- два режима расчета рейтинга: `average` (по среднему рейтингу соперников) и `per_game` (по каждой партии), выбор на уровне турнира;
- конкурентная запись: WAL + `busy_timeout` + оптимистичные версии, конфликт — `409`;
- целевая архитектура: controller → service → model, транзакции в сервисах, единый формат логов и ошибок;
- локализация (i18n): `en` по умолчанию, `ru` вторым языком, хранение выбора в сессии и cookie (`locale`) без префикса в URL, расширение через `config/locales.php` и `lang/<locale>`;
- шахматные клубы (`task_010`): клубный штат `manager`/`arbiter` в `club_user`, множественное членство игроков `club_player` (`0..N`), обязательная привязка турниров к клубу при едином реестре шахматистов и едином рейтинге Elo;
- целевой стек: PHP 8.4+, Laravel 12.x, SQLite 3.
